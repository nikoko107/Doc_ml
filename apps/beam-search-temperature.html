📖 Comprendre les Stratégies de Décodage

🎯 Objectif

Générer du texte token par token en explorant l'espace des séquences possibles. Trade-off entre qualité, diversité et vitesse.

⚡ Enjeu

Espace de recherche énorme (50k tokens → 50kn séquences possibles). Impossible d'explorer tout. Il faut des heuristiques intelligentes.

🔬 Méthodes de Décodage

1️⃣ Greedy Decoding

tokent = argmaxw P(w | context)

Avantages: Rapide, déterministe
Inconvénients: Répétitif, peut manquer de meilleures séquences globales
Utilisation: Traduction automatique simple

2️⃣ Beam Search

Garder k meilleures séquences à chaque étape
Score(seq) = Σ log P(tokeni | context) / length

Beam width k: typiquement 3-10
Avantages: Meilleure qualité globale, explore plusieurs chemins
Inconvénients: k× plus lent, peut être générique/fade
Length normalization: Diviser par longueur pour éviter biais vers séquences courtes
Utilisation: Traduction (Google Translate), résumé

3️⃣ Temperature Sampling

pi = exp(logitsi / T) / Σ exp(logitsj / T)

T → 0: Greedy (déterministe, choisit le plus probable)
T = 1: Distribution originale du modèle
T > 1: Plus aléatoire, explore davantage
T → ∞: Uniforme (perd toute information)
Utilisation: Écriture créative (ChatGPT, Claude)

🎲 Sampling Avancé

Top-k Sampling

Garder seulement les k tokens les plus probables
Redistribuer la probabilité entre eux

k typique: 40-50. Élimine les tokens très improbables qui peuvent causer du non-sens.

Top-p (Nucleus) Sampling

Garder les tokens jusqu'à cumuler p% de probabilité
Nombre dynamique selon contexte

p typique: 0.9-0.95. Adaptatif: garde peu de tokens quand le modèle est sûr, plus quand il hésite.

💡 Combinaison populaire (ChatGPT): Top-p (p=0.95) + Temperature (T=0.7-0.8). Garde l'essentiel de la masse de probabilité tout en ajoutant un peu de randomness.

💡 Paramètres en Pratique

  • Code generation (Codex, Copilot): T=0, top-p=0 (déterministe, précis)
  • Traduction: Beam search k=4-5, length normalization
  • Chat factuel (Claude): T=0.7, top-p=0.95 (équilibré)
  • Écriture créative: T=0.9-1.2, top-p=0.9 (plus de diversité)
  • Brainstorming: T=1.5, top-k=50 (très exploratoire)

Répétition penalty: Réduire la probabilité des tokens déjà générés pour éviter les boucles.
Frequency/presence penalty (OpenAI): Pénaliser les tokens fréquents dans la génération.
