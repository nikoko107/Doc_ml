📚 Définitions Clés - TF-IDF

Term Frequency (TF)
Fréquence d'un mot dans un document. Calculée comme: TF = (nombre d'occurrences du mot) / (nombre total de mots). Mesure l'importance locale du mot dans ce document.
Document Frequency (DF)
Nombre de documents qui contiennent un mot donné. Si un mot apparaît dans tous les documents, il a une DF élevée et est probablement peu informatif.
Inverse Document Frequency (IDF)
Mesure de la rareté d'un mot dans la collection. Formule: IDF = log(N / DF) où N = nombre total de documents. Un IDF élevé signifie que le mot est rare et donc plus distinctif.
TF-IDF Score
Score final calculé par TF × IDF. Élevé quand le mot est fréquent dans CE document mais rare ailleurs. C'est ce qui rend le mot caractéristique et utile pour identifier le sujet.
Normalisation
Les scores TF-IDF sont souvent normalisés (divisés par la longueur du vecteur) pour que les documents de différentes longueurs soient comparables.
Vectorisation
Transformation des documents en vecteurs numériques où chaque dimension représente un mot du vocabulaire avec son score TF-IDF. Permet de comparer mathématiquement les documents.

🎓 TF-IDF - Term Frequency Inverse Document Frequency

TF-IDF est une mesure statistique qui évalue l'importance d'un mot dans un document par rapport à une collection de documents. C'est une amélioration majeure du Bag of Words.

Le problème qu'il résout : Dans BoW, les mots très fréquents comme "le", "la", "de" ont des scores élevés mais peu d'information. TF-IDF pénalise ces mots courants et valorise les mots spécifiques à chaque document.

Formules

TF (Term Frequency) - Fréquence du terme dans le document
TF(t, d) = (nombre d'occurrences de t dans d) / (nombre total de mots dans d)

IDF (Inverse Document Frequency) - Rareté du terme
IDF(t) = log(N / nombre de documents contenant t)
où N = nombre total de documents

TF-IDF
TF-IDF(t, d) = TF(t, d) × IDF(t)

Interprétation :

• TF élevé : Le mot apparaît souvent dans CE document
• IDF élevé : Le mot est rare dans la collection (apparaît dans peu de documents)
• TF-IDF élevé : Mot fréquent dans ce document MAIS rare ailleurs → mot caractéristique !

Exemple : Dans un corpus d'articles sur le sport et la cuisine :

• "ballon" aura un TF-IDF élevé dans les articles de foot
• "recette" aura un TF-IDF élevé dans les articles de cuisine
• "et", "le", "dans" auront un TF-IDF faible partout (trop communs)

Applications :

• Recherche d'information : Moteurs de recherche (Google utilise une variante)
• Extraction de mots-clés : Résumer automatiquement des documents
• Classification de textes : Identifier le sujet d'un document
• Similarité de documents : Trouver des documents similaires
• Chatbots et FAQ : Trouver la meilleure réponse à une question

Avantages par rapport à BoW : Pénalise les mots trop fréquents, met en valeur les mots distinctifs, meilleure représentation sémantique.
