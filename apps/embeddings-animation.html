Étape 1: Les embeddings sont des VECTEURS

Chaque mot est un vecteur (flèche) partant de l'origine. La direction et longueur encodent le sens du mot dans l'espace sémantique (projection 2D d'un espace à 300+ dimensions)

📖 Comprendre les Word Embeddings

🎯 CONCEPT CLÉ : Les Embeddings sont des VECTEURS, pas des points !

❌ Erreur courante : Voir les embeddings comme des "points" dans l'espace

✅ Vision correcte : Les embeddings sont des vecteurs (flèches) partant de l'origine

🧮 Pourquoi ça compte :

  • Un vecteur a une direction (sens sémantique) et une magnitude (intensité)
  • L'arithmétique vectorielle a un sens : V⃗(Roi) - V⃗(Homme) + V⃗(Femme) = V⃗(Reine)
  • Les opérations géométriques (addition, soustraction, produit scalaire) sont définies
  • La similarité cosinus mesure l'angle entre vecteurs, pas la distance

💡 Dans un espace à 300 dimensions (Word2Vec standard), chaque mot est un vecteur avec 300 composantes. Notre visualisation 2D est une projection simplifiée pour comprendre le concept.

🎯 Objectif

Transformer des mots (symboles discrets) en vecteurs continus qui capturent les relations sémantiques et syntaxiques. Les mots similaires ont des vecteurs proches (angle faible).

⚡ Avantages

• Capture le sens contextuel
• Relations arithmétiques vectorielles
• Réduction de dimensionnalité
• Transfer learning entre tâches
• Opérations géométriques définies

🔬 Analogies Vectorielles Célèbres

Ces exemples montrent que l'arithmétique vectorielle capture des relations sémantiques complexes :

Relation de genre:
V⃗(Roi) - V⃗(Homme) + V⃗(Femme) ≈ V⃗(Reine)
V⃗(Oncle) - V⃗(Homme) + V⃗(Femme) ≈ V⃗(Tante)
Relation géographique:
V⃗(Paris) - V⃗(France) + V⃗(Italie) ≈ V⃗(Rome)
V⃗(Tokyo) - V⃗(Japon) + V⃗(Allemagne) ≈ V⃗(Berlin)
Relation grammaticale:
V⃗(Walking) - V⃗(Walk) + V⃗(Swim) ≈ V⃗(Swimming)
V⃗(Bigger) - V⃗(Big) + V⃗(Small) ≈ V⃗(Smaller)

🧮 Similarité Cosinus

cos(θ) = (A · B) / (||A|| × ||B||)

Mesure l'angle entre deux vecteurs:
• 1.0 = vecteurs identiques (angle 0°)
• 0.0 = vecteurs orthogonaux (angle 90°)
• -1.0 = vecteurs opposés (angle 180°)
Plus les mots sont sémantiquement proches, plus leur cosinus est élevé.

⚙️ Méthodes d'Entraînement

Word2Vec (2013)

Skip-gram: Prédit les mots contexte à partir du mot central

"Le chat mange une souris"
Input: "mange" → Output: ["chat", "une"]

CBOW: Prédit le mot central à partir du contexte

GloVe (2014)

Global Vectors - Combine statistiques de co-occurrence et factorisation matricielle

wᵢᵀ·wⱼ + bᵢ + bⱼ = log(Xᵢⱼ)

FastText (2016)

Extension de Word2Vec avec sous-mots (n-grams de caractères). Gère mieux les mots rares et hors vocabulaire.

🚀 Embeddings Contextuels Modernes

  • ELMo (2018): Embeddings contextuels bidirectionnels avec LSTM
  • BERT (2018): Transformers bidirectionnels, masquage de mots, pré-entraîné sur corpus massif
  • GPT-3/4 (2020+): Embeddings issus de modèles autorégressifs massifs (175B+ paramètres)
  • Sentence-BERT: Embeddings de phrases entières pour similarité sémantique

💡 Différence clé: Word2Vec/GloVe donnent un seul vecteur par mot. BERT/ELMo donnent des vecteurs différents selon le contexte:
"La banque de la rivière" vs "Une banque financière" → embeddings différents !

💡 Applications

  • Classification de textes: Sentiment analysis, détection de spam
  • Recherche sémantique: Trouver documents similaires par sens, pas par mots-clés
  • Traduction automatique: Aligner espaces d'embeddings entre langues
  • Question Answering: Comparer question avec passages pour trouver réponse
  • Recommandation: Items similaires basés sur descriptions textuelles

✅ Avantages

  • Capture sens: Mots similaires sémantiquement → vecteurs proches (roi ≈ reine)
  • Arithmétique sémantique: roi - homme + femme = reine, Paris - France + Italie = Rome
  • Pré-entraînés disponibles: Word2Vec, GloVe, FastText téléchargeables gratuitement
  • Légers: 300 dimensions vs millions paramètres Transformers
  • Transfer learning: Embeddings entraînés Wikipedia → utiliser sur domaine spécifique

⚠️ Limites

  • Contexte statique (1 vecteur/mot): "bank" (banque) = même vecteur que "bank" (rive)
  • Remplacés par contextuels (BERT): Word2Vec obsolète vs embeddings contextuels modernes
  • Taille fixe: 300 dim figée, vs Transformers qui adaptent représentation
  • Hors vocabulaire (OOV): Nouveau mot inconnu = pas d'embedding (sauf FastText subwords)
  • Biais culturels: Associations stéréotypées (doctor=homme, nurse=femme) encodées

💼 Cas d'Usage Production

  • Baseline NLP: Point de départ rapide avant Transformers lourds
  • Similarité mots: Recherche synonymes, expansion requêtes, autocomplete
  • Clustering documents: Regrouper articles similaires via moyenne embeddings
  • Word analogies: Complétion relations (king:queen :: man:?), tests linguistiques
  • Features ML classique: Input pour SVM, Random Forest quand BERT trop lourd

🚨 Pièges à Éviter

  • Word2Vec vs GloVe (contexte différent): Word2Vec = fenêtre locale, GloVe = co-occurrence globale. Tester les deux
  • Embeddings non actualisés: Word2Vec 2013 ignore mots post-2013 ("selfie", "ChatGPT")
  • Polysémie (bank = banque vs rive): Embedding unique rate les sens multiples. Utiliser BERT si critique
  • Moyenne naïve embeddings: Moyenner vecteurs mots = perd syntaxe. Ok pour baseline, mauvais si précision nécessaire
  • Ignorer preprocessing: Lowercase, lemmatization, stopwords impact qualité embeddings
  • Dimension trop basse (50): Perd nuances. Standard 300 dim pour équilibre performance/taille
