Étape 1: Forward Propagation

Les données traversent le réseau couche par couche, chaque neurone calcule z = W·x + b puis applique σ(z)

📖 Comprendre l'Entraînement des Réseaux de Neurones

🎯 Objectif

Apprendre automatiquement les poids et biais optimaux pour minimiser l'erreur entre prédictions (ŷ) et valeurs réelles (y) sur un ensemble de données.

⚡ Architecture

• Input Layer: Reçoit les features
• Hidden Layers: Extraient représentations
• Output Layer: Produit prédictions
• Fully connected: Chaque neurone connecté à tous les suivants

🔄 Cycle d'Entraînement (Epoch)

  1. Forward Propagation: Calcul des activations couche par couche
    z(l) = W(l) · a(l-1) + b(l)
    a(l) = σ(z(l))     // Fonction d'activation (ReLU, sigmoid, tanh)
  2. Loss Calculation: Mesure de l'erreur entre prédiction et cible
    MSE: L = ½(y - ŷ)²
    Cross-Entropy: L = -y·log(ŷ) - (1-y)·log(1-ŷ)
  3. Backward Propagation: Calcul des gradients via la chaîne de dérivation
    ∂L/∂W(l) = ∂L/∂a(l) · ∂a(l)/∂z(l) · ∂z(l)/∂W(l)
    δ(l) = (W(l+1))T · δ(l+1) ⊙ σ'(z(l))
  4. Weight Update: Optimisation des paramètres avec l'optimiseur
    W(l) ← W(l) - α · ∂L/∂W(l)
    b(l) ← b(l) - α · ∂L/∂b(l)

🔬 Fonctions d'Activation

ReLU

σ(z) = max(0, z)

Plus populaire, résout vanishing gradient

Sigmoid

σ(z) = 1/(1+e-z)

Sortie [0,1], classification binaire

Tanh

σ(z) = tanh(z)

Sortie [-1,1], centré en zéro

⚙️ Optimiseurs Modernes

SGD avec Momentum

v = β·v + (1-β)·∇W
W ← W - α·v

Accélère convergence, réduit oscillations

Adam (Adaptive Moment)

m = β₁·m + (1-β₁)·∇W
v = β₂·v + (1-β₂)·∇W²
W ← W - α·m/√(v+ε)

Le plus populaire, learning rate adaptatif

💡 Hyperparamètres Clés

  • Learning Rate (α): Taille des pas lors de l'optimisation (typiquement 0.001 - 0.1)
  • Batch Size: Nombre d'exemples par mise à jour (32, 64, 128, 256)
  • Epochs: Nombre de passages complets sur le dataset
  • Hidden Units: Nombre de neurones par couche cachée
  • Regularization (L1/L2, Dropout): Prévention du surapprentissage

🚀 Améliorations Modernes

  • Batch Normalization: Normalise activations entre couches pour stabiliser l'entraînement
  • Dropout: Désactive aléatoirement des neurones pour éviter le surapprentissage
  • Skip Connections (ResNet): Connexions directes qui sautent des couches
  • Learning Rate Scheduling: Réduction progressive du learning rate
  • Early Stopping: Arrêt si validation loss ne s'améliore plus
