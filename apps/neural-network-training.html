🎓 Les 4 Étapes de l'Entraînement d'un Réseau de Neurones

🔹 Étape 1 : Forward Pass (Propagation Avant)

Calcul de la sortie du réseau à partir des entrées :

z = w·x + b
a = activation(z)
ŷ = sortie finale

Où w = poids, x = entrées, b = biais

🔹 Étape 2 : Calcul de l'Erreur (Loss)

Mesurer l'écart entre prédiction et réalité :

Loss = MSE = (1/n) Σ (y - ŷ)²

Plus la loss est petite, meilleur est le modèle

🔹 Étape 3 : Backward Pass (Backpropagation)

Calculer les gradients (comment l'erreur change avec chaque poids) :

∂Loss/∂w = gradient du poids
∂Loss/∂b = gradient du biais

Utilise la règle de la chaîne : propagation de l'erreur de la sortie vers l'entrée

🔹 Étape 4 : Mise à Jour (Gradient Descent)

Ajuster les poids pour réduire l'erreur :

w = w - α · ∂Loss/∂w
b = b - α · ∂Loss/∂b

Où α = taux d'apprentissage (learning rate)

🔄 Cycle Complet

1️⃣ Forward : Calcul de la prédiction
2️⃣ Loss : Mesure de l'erreur
3️⃣ Backward : Calcul des gradients
4️⃣ Update : Correction des poids
🔁 Répéter jusqu'à convergence (loss → 0)

✅ Réseau Entraîné

Le réseau a appris à classifier les données. En phase d'inférence, il utilise les poids entraînés (figés) pour faire des prédictions sur de nouvelles données.

🎯 Phase d'Inférence : Utilisation du Modèle

Une fois le réseau entraîné, nous entrons en phase d'inférence. C'est la phase de production où le modèle est utilisé pour faire des prédictions sur de nouvelles données.

🔍 Différences Entraînement vs Inférence

Aspect Entraînement Inférence
Poids Modifiés (appris) Figés (constants)
Phases Forward + Backward Forward uniquement
Données Dataset d'entraînement Nouvelles données
Objectif Minimiser la loss Prédire la classe/valeur

💡 En Production

• Entraînement : Fait une fois (ou périodiquement pour recycler le modèle)
• Inférence : Exécutée des millions de fois par jour
• Optimisation : L'inférence doit être RAPIDE (quantization, pruning, distillation)
• Batch inference : Grouper les requêtes pour meilleure performance GPU
