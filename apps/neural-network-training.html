🔬 Réseau de Neurones

🧠 Le Principe du Neurone Artificiel

Un neurone artificiel est une unité de calcul simple inspirée du cerveau humain. Voici comment il fonctionne, étape par étape :

📥 Étape 1 : Réception des Entrées

Le neurone reçoit plusieurs entrées (inputs). Par exemple : x₁ = 0.5, x₂ = 0.8

Entrées : [x₁, x₂] = [0.5, 0.8]

⚖️ Étape 2 : Multiplication par les Poids

Chaque entrée est multipliée par un poids (weight). Les poids déterminent l'importance de chaque entrée.

Poids : [w₁, w₂] = [0.3, -0.7]
Multiplications : x₁×w₁ = 0.5×0.3 = 0.15
                 x₂×w₂ = 0.8×(-0.7) = -0.56

➕ Étape 3 : Somme Pondérée + Biais

On additionne toutes les multiplications et on ajoute un biais (bias).

Biais : b = 0.1
Somme : z = (x₁×w₁) + (x₂×w₂) + b
       z = 0.15 + (-0.56) + 0.1
       z = -0.31

⚡ Étape 4 : Fonction d'Activation

La somme passe dans une fonction d'activation qui transforme la valeur.

ReLU (Rectified Linear Unit) :
→ Si z > 0 : sortie = z
→ Si z ≤ 0 : sortie = 0

Pour notre exemple : z = -0.31
Sortie ReLU = 0 (car -0.31 ≤ 0)

Sigmoid : sortie = 1 / (1 + e^(-z))
→ Transforme n'importe quelle valeur entre 0 et 1

Tanh : sortie = tanh(z)
→ Transforme n'importe quelle valeur entre -1 et 1

📤 Étape 5 : Sortie du Neurone

La valeur après activation devient la sortie du neurone, qui peut être :

  • Envoyée à d'autres neurones dans la couche suivante
  • Utilisée comme prédiction finale si c'est la couche de sortie

💡 Résumé du Neurone

1. Reçoit des entrées (x₁, x₂, ...)
2. Multiplie chaque entrée par son poids (w₁, w₂, ...)
3. Additionne tout + ajoute le biais (b)
4. Applique une fonction d'activation (ReLU, Sigmoid, Tanh)
5. Produit une sortie

⚡ L'apprentissage consiste à ajuster les poids et biais pour que le neurone produise la bonne sortie !

🎓 Comment fonctionne cette animation ?

Cette application montre l'entraînement complet d'un réseau de neurones en temps réel :

  1. Epoch 1 : Le réseau commence avec des poids aléatoires → frontière de décision chaotique
  2. Epochs 2-20 : Le réseau apprend progressivement → la frontière s'améliore
  3. Epochs 20-50 : Fine-tuning → la frontière devient optimale
  4. Graphique de loss : Vous voyez l'erreur diminuer en temps réel

📊 Les Datasets

  • XOR : Le problème classique impossible à résoudre avec un perceptron simple
  • Spirale : Pattern très complexe nécessitant un réseau profond
  • Cercles : Frontière circulaire non-linéaire
  • Linéaire : Séparation simple pour comprendre les bases

🎯 Utilisation pour Formation

Scénario de démonstration recommandé :

  1. Commencez avec Linéaire → Montrez que ça converge rapidement
  2. Passez à XOR → Montrez la complexité du problème
  3. Augmentez les neurones cachés (4 → 8 → 16) → Montrez l'impact
  4. Testez Spirale → Montrez un cas vraiment difficile
  5. Changez l'activation (ReLU vs Sigmoid) → Montrez les différences
