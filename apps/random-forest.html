⚙️ Contrôles

💡 Random Forest:
• 3 arbres indépendants
• Chaque arbre voit un échantillon bootstrap (8 points tirés aléatoirement avec remplacement)
• Chaque nœud a un threshold (seuil de décision)
• Vote majoritaire pour la prédiction finale
• L'arbre le plus précis est surligné en vert

🎓 Comment fonctionne Random Forest ?

Random Forest est un algorithme d'ensemble qui combine plusieurs arbres de décision pour créer un modèle robuste.

Étape 1: Bootstrap Sampling (Échantillonnage avec remplacement) Pour chaque arbre: • Tirer aléatoirement 8 points depuis le dataset original • Un point peut être tiré plusieurs fois (cercles avec bordure épaisse) • Certains points peuvent ne jamais être tirés Étape 2: Construction de l'Arbre Pour chaque nœud: • Choisir une feature aléatoire (X ou Y) • Trouver le meilleur threshold (seuil) • Exemple: "X < 0.45" → diviser en 2 branches • Continuer jusqu'à atteindre les feuilles (décision finale) Étape 3: Vote Majoritaire Pour prédire un nouveau point: • Chaque arbre vote (Classe A ou Classe B) • La classe avec le plus de votes gagne • Exemple: [B, B, A] → Prédiction finale = B

Pourquoi ça fonctionne ?

1. Diversité: Chaque arbre voit des données différentes (bootstrap)
2. Indépendance: Les arbres font des erreurs différentes
3. Sagesse collective: Le vote majoritaire réduit les erreurs individuelles
4. Robustesse: Si un arbre se trompe, les autres peuvent compenser

Exemple Concret

Imaginez 3 médecins (arbres) diagnostiquant un patient (point test):
• Médecin 1: Voit uniquement les symptômes A, B, D → Diagnostic: Grippe
• Médecin 2: Voit uniquement les symptômes A, C, D → Diagnostic: Grippe
• Médecin 3: Voit uniquement les symptômes B, C, E → Diagnostic: Rhume
• Vote final: 2 votes pour Grippe, 1 vote pour Rhume → Diagnostic: Grippe

Applications Entreprise

• Banque: Détection de fraude, scoring de crédit
• E-commerce: Prédiction de churn, recommandations
• Santé: Diagnostic médical assisté par IA
• Industrie: Maintenance prédictive des machines
