🎓 Random Forest - Ensemble Learning

Random Forest est un algorithme d'ensemble créé par Leo Breiman en 2001. Il combine plusieurs arbres de décision pour créer un modèle robuste et performant.

Principe: 1. Créer N arbres de décision 2. Pour chaque arbre: - Échantillonner avec remplacement (bootstrap) - Sélectionner aléatoirement un sous-ensemble de features - Entraîner l'arbre sur cet échantillon 3. Prédiction finale = vote majoritaire (classification) ou moyenne (régression)

Avantages

• Robuste: Résiste au surapprentissage (pas besoin de pruning)
• Précis: Performances excellentes sur la plupart des problèmes
• Feature Importance: Identifie les variables les plus importantes
• Versatile: Classification et régression
• Parallélisable: Chaque arbre peut être entraîné indépendamment

Hyperparamètres Clés

• n_estimators: Nombre d'arbres (plus = mieux, mais + lent) • max_depth: Profondeur maximale des arbres • max_features: Nombre de features par split (√n pour classification) • min_samples_split: Min d'échantillons pour diviser un noeud • bootstrap: Utiliser le bootstrap ou non

Applications Entreprise

• Détection de fraude bancaire
• Scoring de crédit
• Prédiction de churn client
• Diagnostic médical
• Recommandation produits
• Maintenance prédictive
