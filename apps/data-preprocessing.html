🎓 Impact du Prétraitement sur la Régression Linéaire

La régression linéaire est très sensible aux outliers. Une seule erreur de saisie peut complètement fausser la droite de prédiction. Cette application interactive vous permet de voir l'effet de chaque technique en temps réel !

1. Détection et Suppression des Outliers

Méthode IQR (Interquartile Range) IQR = Q3 - Q1 (Quartile 3 - Quartile 1) Outlier si : • Prix < Q1 - 1.5 × IQR (trop bas) • Prix > Q3 + 1.5 × IQR (trop haut) Action : SUPPRESSION réelle des outliers détectés → Le dataset nettoyé ne contient plus les erreurs → La régression est calculée sur des données fiables → MSE réduite de ~85-95% typiquement

2. Les Trois Normalisations

Min-Max Scaling [0, 1] X_norm = (X - X_min) / (X_max - X_min) → Ramène toutes les valeurs entre 0 et 1 → Préserve la distribution originale → Sensible aux outliers (nettoyer AVANT) → Utilisé pour réseaux neurones, images Z-Score Standardization (μ=0, σ=1) X_norm = (X - μ) / σ → Moyenne = 0, Écart-type = 1 → Données centrées et réduites → Assume distribution normale → Utilisé pour régression, PCA Robust Scaling X_norm = (X - médiane) / IQR → Utilise médiane et IQR → Plus robuste que Min-Max et Z-Score → Résistant aux outliers → Idéal si outliers légitimes

3. Pourquoi Normaliser ?

Pour la régression linéaire simple (1 feature), la normalisation ne change pas la qualité du modèle, juste l'échelle des coefficients. La relation linéaire est préservée.

Mais pour la régression multiple (plusieurs features) :

• Sans normalisation : Les features avec grandes valeurs (ex: superficie 0-200) dominent celles avec petites valeurs (ex: chambres 1-5)
• Avec normalisation : Toutes les features contribuent équitablement
• Essentiel pour : Régression Ridge/Lasso (régularisation), Gradient Descent (convergence)

4. Pipeline Correct de Prétraitement

Ordre OBLIGATOIRE : 1. Exploration des données (visualisation, statistiques) 2. Détection des outliers (IQR, Z-score, box plot) 3. ⚠️ Décision : Supprimer ou garder ? → Erreurs de saisie : SUPPRIMER → Valeurs extrêmes légitimes : GARDER ou transformer 4. ⚠️ SPLIT train/test (70/30 ou 80/20) 5. Calcul paramètres normalisation sur TRAIN uniquement → fit() sur train 6. Application normalisation sur train ET test → transform() sur train et test avec mêmes paramètres 7. Entraînement du modèle 8. Évaluation sur test ERREUR FATALE (Data Leakage) : ❌ Normaliser AVANT split train/test → Les statistiques du test "leakent" dans le train → Performance optimiste mais fausse en production ! ✅ CORRECT : Split puis normaliser → Calcul min/max/mean UNIQUEMENT sur train → Application sur train ET test avec ces valeurs

5. Quand Normaliser ?

• OBLIGATOIRE : Régression Ridge/Lasso, SVM, KNN, Réseaux de neurones
• RECOMMANDÉ : Régression linéaire multiple, Gradient Descent, PCA
• PAS NÉCESSAIRE : Régression linéaire simple, Arbres de décision, Random Forest

Pourquoi ? Les algorithmes basés sur les distances ou les gradients sont sensibles aux échelles. Les arbres font des splits sur des valeurs absolues, pas des distances.
