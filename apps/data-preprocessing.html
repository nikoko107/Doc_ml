🎓 Prétraitement de Données - Guide Entreprise

Le prétraitement est l'étape la plus importante en ML : "Garbage in, garbage out". 80% du temps d'un data scientist est consacré au nettoyage et préparation des données.

1. Normalisation / Standardisation

Min-Max Scaling (0-1)
X_scaled = (X - X_min) / (X_max - X_min)
→ Tous les features sur [0, 1]
→ Préserve la distribution originale
→ Sensible aux outliers

Z-Score Standardization
X_scaled = (X - μ) / σ
→ Moyenne = 0, Écart-type = 1
→ Assume distribution normale
→ Sensible aux outliers

Robust Scaling
X_scaled = (X - median) / IQR
→ Utilise médiane et quartiles
→ Résistant aux outliers
→ Idéal pour données réelles

Quand normaliser ?

• Obligatoire: KNN, SVM, réseaux de neurones, régression régularisée
• Pas nécessaire: Arbres de décision, Random Forest, XGBoost
• Recommandé: PCA, clustering (K-means)

2. Détection des Outliers

Méthode IQR (Interquartile Range)
IQR = Q3 - Q1
Outlier si: X < Q1 - 1.5×IQR ou X > Q3 + 1.5×IQR
→ Méthode robuste, non-paramétrique
→ Fonctionne sur toutes distributions

Méthode Z-Score
Z = (X - μ) / σ
Outlier si: |Z| > 3
→ Assume distribution normale
→ Simple et rapide
→ Sensible aux outliers extrêmes

Que faire des outliers ?

1. Analyser : Erreur de mesure ou vraie valeur extrême ?
2. Supprimer : Si erreur évidente
3. Transformer : Log, racine carrée, winsorization
4. Garder : Si information importante (fraude, anomalie)
5. Modèle robuste : Utiliser algorithmes résistants (arbres, Huber loss)

3. Valeurs Manquantes

Stratégies d'imputation:

• Moyenne: Pour features numériques continues
→ Rapide mais ignore la distribution

• Médiane: Si outliers ou distribution asymétrique
→ Plus robuste que la moyenne

• Mode: Pour features catégorielles
→ Valeur la plus fréquente

• Suppression: Si < 5% de données manquantes
→ Attention au biais!

• Avancé: KNN imputation, régression, MICE
→ Plus précis mais plus coûteux

Types de valeurs manquantes:

• MCAR (Missing Completely At Random) : Aléatoire pur → Suppression OK
• MAR (Missing At Random) : Dépend d'autres variables → Imputation
• MNAR (Missing Not At Random) : Lié à la valeur elle-même → Modélisation complexe

4. Pipeline de Prétraitement en Entreprise

Ordre recommandé:

1. Exploration des données (EDA)
2. Gestion des valeurs manquantes
3. Détection des outliers
4. Feature engineering
5. Encodage des catégories
6. Split train/test
7. Normalisation (fit sur train, transform sur test)
8. Validation

Erreurs fréquentes à éviter:

❌ Normaliser avant split train/test (data leakage!)
❌ Supprimer outliers sans analyse
❌ Utiliser la moyenne avec outliers
❌ Oublier de sauvegarder les paramètres de transformation
✅ Pipeline reproductible et documenté
