🎓 Impact du Prétraitement sur la Régression Linéaire

La régression linéaire est très sensible aux outliers. Une seule erreur de saisie peut complètement fausser la droite de prédiction. Le prétraitement est donc crucial !

1. Détection des Outliers avec IQR

Méthode IQR (Interquartile Range) IQR = Q3 - Q1 (Quartile 3 - Quartile 1) Outlier si : • Prix < Q1 - 1.5 × IQR (trop bas) • Prix > Q3 + 1.5 × IQR (trop haut) Action : SUPPRESSION réelle des outliers détectés → Le dataset nettoyé ne contient plus les erreurs → La régression est calculée sur des données fiables

2. Impact des Outliers sur la Régression

La régression linéaire minimise la somme des carrés des erreurs (MSE). Les outliers, étant très éloignés, créent des erreurs énormes qui "tirent" la droite vers eux.

Exemple concret : AVEC outliers (erreur : 180m² à 80k€ au lieu de ~360k€) : → Équation : Prix = 0.8 × Superficie + 150 → MSE élevée : ~4000 k€² → Prédiction pour 100m² : 230k€ (trop bas !) SANS outliers (données nettoyées) : → Équation : Prix = 2.0 × Superficie + 100 → MSE faible : ~200 k€² → Prédiction pour 100m² : 300k€ (correct !) Amélioration : MSE réduite de 95% !

3. Les Trois Normalisations

Min-Max Scaling [0, 1] X_norm = (X - X_min) / (X_max - X_min) → Ramène toutes les valeurs entre 0 et 1 → Préserve la distribution originale → Sensible aux outliers (c'est pourquoi on nettoie AVANT) Z-Score Standardization (μ=0, σ=1) X_norm = (X - μ) / σ → Moyenne = 0, Écart-type = 1 → Données centrées et réduites → Assume distribution normale Robust Scaling X_norm = (X - médiane) / IQR → Utilise médiane et IQR (résistant aux outliers) → Plus robuste que Min-Max et Z-Score → Idéal si on garde certains outliers légitimes

4. Pourquoi Normaliser ?

Pour la régression linéaire simple (1 feature), la normalisation ne change pas la qualité du modèle, juste l'échelle des coefficients.

Mais pour la régression multiple (plusieurs features) :

• Sans normalisation : Les features avec grandes valeurs (ex: superficie 0-200) dominent celles avec petites valeurs (ex: chambres 1-5)
• Avec normalisation : Toutes les features contribuent équitablement
• Essentiel pour : Régression Ridge/Lasso (régularisation), Gradient Descent (convergence)

5. Pipeline Correct

Ordre OBLIGATOIRE : 1. Exploration des données (visualisation) 2. Détection des outliers (IQR, Z-score, box plot) 3. Suppression des outliers (erreurs de saisie) 4. ⚠️ SPLIT train/test (70/30 ou 80/20) 5. Calcul des paramètres de normalisation sur TRAIN uniquement → fit() sur train 6. Application de la normalisation sur train ET test → transform() sur train et test 7. Entraînement du modèle 8. Évaluation sur test ERREUR FATALE (Data Leakage) : ❌ Normaliser AVANT split train/test → Les statistiques du test "leakent" dans le train → Performance optimiste mais fausse en production ! ✅ CORRECT : Split puis normaliser → Calcul min/max/mean UNIQUEMENT sur train → Application sur train ET test

6. Quand Normaliser ?

• OBLIGATOIRE : Régression Ridge/Lasso, SVM, KNN, Réseaux de neurones
• RECOMMANDÉ : Régression linéaire multiple, Gradient Descent, PCA
• PAS NÉCESSAIRE : Régression linéaire simple, Arbres de décision, Random Forest
