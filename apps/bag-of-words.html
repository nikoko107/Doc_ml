🎓 Bag of Words (Sac de Mots)

Le Bag of Words est une représentation classique en NLP qui représente un document comme un vecteur de fréquences de mots, sans tenir compte de l'ordre des mots.

Exemple avec vocabulaire = ["chat", "dort", "mange"]

"le chat dort" → [1, 1, 0] (1 "chat", 1 "dort", 0 "mange")
"le chat mange" → [1, 0, 1]
"le chat dort et mange" → [1, 1, 1]

Différence avec One-Hot Encoding :

• One-Hot : Représente UN mot avec un vecteur binaire (1 seul "1")
• Bag of Words : Représente UN DOCUMENT avec un vecteur de comptages (plusieurs valeurs > 0)

Comment ça marche :

1. Construire le vocabulaire de tous les documents
2. Pour chaque document, compter combien de fois chaque mot du vocabulaire apparaît
3. Créer un vecteur de taille |vocabulaire| avec ces comptages

Avantages :

• Simple et efficace
• Fonctionne bien pour la classification de documents
• Base de nombreux algorithmes (Naive Bayes, etc.)
• Capture l'importance des mots par leur fréquence

Inconvénients :

• Perd l'ordre des mots ("pas bon" = "bon pas")
• Vecteurs très grands et creux pour gros corpus
• Mots fréquents (le, la, de) peuvent dominer
• Pas de notion de sémantique ou contexte

Applications : Classification de textes, filtrage de spam, analyse de sentiment, recherche d'information, clustering de documents.

Amélioration : TF-IDF pondère les fréquences pour réduire l'impact des mots trop fréquents.

📚 Définitions Clés

Fréquence du terme (TF)
Nombre de fois qu'un mot apparaît dans un document
Mots vides (Stop words)
Mots très fréquents mais peu informatifs (le, la, de, et, dans...)
Corpus
Collection de documents textuels utilisés pour l'analyse
Feature Vector
Vecteur numérique représentant un document dans l'espace du vocabulaire
