💡 SVM:
• Trouve l'hyperplan optimal
• Maximise la marge entre classes
• Kernel trick pour non-linéaire
• Robuste aux outliers

Comment ça marche:
1. Choisissez un kernel (Linéaire, RBF ou Polynomial)
2. Ajoutez des points de chaque classe en cliquant
3. Cliquez sur "Entraîner SVM" pour voir la frontière
4. Les points avec un cercle noir sont les Support Vectors
5. Essayez "Motif XOR" ou "Cercles" pour tester les kernels non-linéaires

Astuce: RBF fonctionne bien pour les données complexes !

📚 Définitions Clés - SVM

Marge
Distance entre la frontière de décision et les points les plus proches de chaque classe. SVM cherche à maximiser cette marge pour une meilleure généralisation.
Hyperplan
Frontière de décision qui sépare les classes. En 2D c'est une ligne, en 3D un plan, en dimension supérieure un hyperplan. Défini par w·x + b = 0.
Vecteurs de Support (Support Vectors)
Points les plus proches de la frontière (marqués par un cercle noir). Ce sont les seuls points qui déterminent l'hyperplan - tous les autres peuvent être ignorés.
Kernel (Noyau)
Fonction qui permet de projeter les données dans un espace de dimension supérieure sans calcul explicite. Permet à SVM de résoudre des problèmes non-linéaires.
Espace de Caractéristiques
Espace de dimension supérieure où les données deviennent linéairement séparables. Le kernel trick évite de calculer explicitement ces coordonnées.
Paramètre C (Régularisation)
Contrôle le compromis entre marge large et erreurs. C élevé = peu d'erreurs tolérées (risque overfitting), C faible = marge plus large (plus de robustesse).

🎓 Support Vector Machines (SVM)

SVM est un algorithme puissant développé par Vladimir Vapnik en 1995. Il cherche l'hyperplan qui sépare au mieux les classes avec la marge maximale.

Objectif: Maximiser la marge = 2/||w|| sous contrainte: y_i(w·x_i + b) ≥ 1 Support Vectors: Points les plus proches de la frontière Seuls ces points déterminent l'hyperplan

Le Kernel Trick

Pour des données non-linéairement séparables, SVM utilise le kernel trick qui projette les données dans un espace de dimension supérieure sans calcul explicite.

Kernels Courants: • Linéaire: K(x,y) = x·y → Problèmes linéairement séparables • RBF (Gaussian): K(x,y) = exp(-γ||x-y||²) → Très flexible, par défaut • Polynomial: K(x,y) = (x·y + c)^d → Interactions polynomiales • Sigmoid: K(x,y) = tanh(κx·y + c) → Réseaux de neurones

Hyperparamètres

• C (régularisation): - C grand: Marge étroite, peu d'erreurs (risque overfitting) - C petit: Marge large, tolère erreurs (régularisation) • γ (gamma pour RBF): - γ grand: Influence locale (risque overfitting) - γ petit: Influence globale (généralisation)

Avantages & Limitations

✅ Avantages:
• Efficace en haute dimension
• Mémoire efficace (seuls support vectors)
• Versatile (kernels différents)
• Robuste mathématiquement

⚠️ Limitations:
• Lent sur gros datasets (O(n³))
• Sensible au choix du kernel et hyperparamètres
• Pas de probabilités directes
• Difficile à interpréter

Applications Entreprise

• Classification de textes et spam
• Reconnaissance d'images et visages
• Bioinformatique (classification protéines)
• Détection d'anomalies financières
• Diagnostic médical
