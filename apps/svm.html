🎓 Comment fonctionne cette animation ?

Cette application montre l'entraînement complet d'un SVM étape par étape :

  1. Initialisation : Le SVM commence avec un hyperplan aléatoire
  2. Recherche des vecteurs de support : Identification des points les plus proches de la frontière
  3. Optimisation de la marge : Ajustement de l'hyperplan pour maximiser la distance aux vecteurs de support
  4. Convergence : L'algorithme s'arrête quand la marge est optimale
Objectif du SVM :

Maximiser la marge : 2 / ||w||

Sous contrainte : yi(w·xi + b) ≥ 1 pour tous les points

où :
• w = vecteur normal à l'hyperplan
• b = biais
• yi = label (-1 ou +1)
• xi = point de données

🔄 Les Kernels (Noyaux)

Pour les données non-linéairement séparables, le SVM utilise des kernels pour projeter les données dans un espace de dimension supérieure où elles deviennent séparables.

Kernel Linéaire : K(x, y) = x · y
→ Pour données déjà séparables par une droite

Kernel RBF (Radial Basis Function) :
K(x, y) = exp(-γ ||x - y||²)
→ Pour frontières complexes et non-linéaires (XOR, cercles)

Kernel Polynomial :
K(x, y) = (x · y + c)d
→ Pour frontières courbes

💡 Conseils Pédagogiques

  • Dataset Linéaire : Parfait pour comprendre le concept de base - utilisez kernel linéaire
  • Dataset XOR : Impossible à séparer avec kernel linéaire - passez à RBF pour voir la magie !
  • Dataset Cercles : Montre la puissance du kernel RBF pour des formes circulaires
  • Paramètre C : C faible = marge large mais tolère erreurs | C élevé = marge stricte mais risque de surapprentissage
