📖 Comprendre les Transformers

🎯 Innovation

Architecture "Attention Is All You Need" (2017). Remplace les RNN/LSTM par le mécanisme d'attention pour traiter les séquences en parallèle.

⚡ Avantages

• Parallélisation massive
• Capture dépendances longue distance
• Pas de vanishing gradient
• Interprétabilité via poids d'attention

🔬 Mécanisme d'Attention Self-Attention

1️⃣ Projections Q, K, V

Q = X · WQ   // Query: "Que cherché-je ?"
K = X · WK   // Key: "Que suis-je ?"
V = X · WV   // Value: "Mon contenu sémantique"

Chaque mot est projeté en 3 vecteurs via des matrices de poids apprises WQ, WK, WV

2️⃣ Calcul des Scores d'Attention

scores = Q · KT / √dk

Produit scalaire entre Query et toutes les Keys. Division par √dk pour stabiliser les gradients. Score élevé = forte relation entre les mots.

3️⃣ Softmax et Normalisation

attention_weights = softmax(scores)

Softmax transforme les scores en probabilités (somme = 1). Les poids élevés indiquent les mots importants pour le contexte.

4️⃣ Agrégation Pondérée

output = attention_weights · V

Somme pondérée des Values selon les poids d'attention. Chaque mot reçoit l'information contextuelle des autres mots.

👁️ Multi-Head Attention

Au lieu d'une seule attention, on utilise plusieurs "têtes" en parallèle pour capturer différentes relations :

Tête 1: Syntaxe

Adjectif → Nom
Verbe → Sujet
Relations grammaticales

Tête 2: Sémantique

Coréférence
Anaphores
Relations thématiques

Tête 3: Position

Ordre des mots
Distance
Structure phrastique

💡 Exemple: Dans "Le chat noir mange", une tête capture "noir → chat" (accord adjectif-nom), une autre "mange → chat" (relation verbe-sujet), une troisième les positions relatives.

🏗️ Architecture Complète

Encoder (traitement de l'entrée)

  1. Input Embeddings + Positional Encoding
  2. Multi-Head Self-Attention (chaque mot attend tous les autres)
  3. Add & Norm (skip connection + layer normalization)
  4. Feed-Forward Network (MLP par position)
  5. Add & Norm
  6. Répéter N fois (ex: 6 couches pour BERT base)

Decoder (génération de la sortie)

  1. Output Embeddings + Positional Encoding
  2. Masked Multi-Head Self-Attention (ne voit que le passé)
  3. Add & Norm
  4. Cross-Attention (attend l'encoder)
  5. Add & Norm
  6. Feed-Forward Network
  7. Add & Norm
  8. Répéter N fois

🚀 Modèles Célèbres

  • BERT (2018): Encoder-only, bidirectionnel, pré-entraîné sur MLM + NSP (110M-340M params)
  • GPT-3 (2020): Decoder-only, autorégressif, 175 milliards de paramètres
  • T5 (2019): Encoder-decoder, tout en text-to-text (11B params)
  • GPT-4 (2023): Multimodal (texte + images), >1T params (architecture secrète)
  • Llama 2 (2023): Open-source, 7B-70B params, optimisé pour instruction following
  • Claude (Anthropic): Constitutional AI, 100k+ tokens de contexte

💡 Applications

  • Traduction automatique: Seq2seq avec attention (Google Translate, DeepL)
  • Génération de texte: GPT-3/4, ChatGPT, articles, code, poésie
  • Question Answering: BERT fine-tuné sur SQuAD, systèmes de Q&A
  • Résumé automatique: T5, BART pour abstractive summarization
  • Classification: Sentiment analysis, détection de spam, NER
  • Vision: Vision Transformer (ViT) pour classification d'images

📚 Définitions

Self-Attention ?
Mécanisme permettant à chaque élément d'une séquence d'attendre tous les autres éléments pour capturer les relations contextuelles
Softmax ?
Fonction d'activation qui convertit des scores bruts en distribution de probabilités (valeurs entre 0 et 1, somme = 1)
Embedding ?
Représentation vectorielle dense d'un mot ou token, apprise pendant l'entraînement, qui encode son sens sémantique
Multi-Head Attention ?
Plusieurs couches d'attention en parallèle, chacune capturant différents types de relations (syntaxe, sémantique, position)
Positional Encoding ?
Vecteurs ajoutés aux embeddings pour indiquer la position des mots dans la séquence, car l'attention est permutation-invariante
