Régression Linéaire ?

Convergence de l'erreur ?

🎓 Comment ça marche ?

La régression linéaire utilise la descente de gradient pour optimiser les paramètres m (pente) et b (ordonnée). Vous pouvez choisir différentes fonctions de perte:

📐 Solution Analytique Optimale

Pour le cas 2D (y = mx + b):

m = Σ((xᵢ - x̄)(yᵢ - ȳ)) / Σ((xᵢ - x̄)²)
b = ȳ - m·x̄

Où x̄ et ȳ sont les moyennes des coordonnées x et y

Formulation alternative:

m = (n·Σ(xᵢyᵢ) - Σxᵢ·Σyᵢ) / (n·Σ(xᵢ²) - (Σxᵢ)²)
b = (Σyᵢ - m·Σxᵢ) / n

Où n est le nombre de points

Pour n dimensions (régression multiple):

β = (XTX)-1 XTy

Où:
• β = vecteur des coefficients [b, m₁, m₂, ..., mₙ]
• X = matrice de design (chaque ligne = [1, x₁, x₂, ..., xₙ])
• y = vecteur des valeurs cibles
• XT = transposée de X
• (XTX)-1 = inverse de la matrice XTX

💡 Note: Ces formules donnent la solution optimale exacte pour MSE en une seule étape (pas d'itérations nécessaires). La descente de gradient utilisée dans cette application converge progressivement vers cette même solution.

MSE (Mean Squared Error)

MSE = (1/n) Σ (yᵢ - ŷᵢ)²

Sensible aux outliers, pénalise fortement les grandes erreurs (au carré)

MAE (Mean Absolute Error)

MAE = (1/n) Σ |yᵢ - ŷᵢ|

Robuste aux outliers, traite toutes les erreurs de manière égale (valeur absolue)

⚡ Visualisation en temps réel:

  • 2 droites de régression simultanées - MSE (ligne bleue 🔵), MAE (ligne verte 🟢)
  • 2 courbes de convergence - Comparez l'évolution des 2 métriques (MSE, MAE) en temps réel
  • Double échelle - Chaque métrique a sa propre échelle pour une meilleure visualisation
  • Gradients adaptatifs - Chaque modèle utilise ses propres gradients pour converger indépendamment

📚 Définitions

Régression Linéaire ?
Méthode statistique pour modéliser la relation entre une variable dépendante et une ou plusieurs variables indépendantes
Descente de Gradient ?
Algorithme d'optimisation itératif qui ajuste progressivement les paramètres pour minimiser l'erreur
Outlier (Valeur Aberrante) ?
Point de données qui se situe loin de la tendance générale et peut influencer fortement le modèle
Taux d'Apprentissage ?
Paramètre qui contrôle la vitesse de convergence de l'algorithme (valeur entre 0.001 et 0.5)

📊 Analyse : Quand utiliser la régression linéaire ?

✅ Avantages

  • Simplicité : Facile à comprendre et à interpréter
  • Rapidité : Entraînement très rapide, même sur gros datasets
  • Interprétabilité : Chaque coefficient a un sens clair (impact de chaque variable)
  • Peu d'hyperparamètres : Pas de tuning complexe nécessaire
  • Solution analytique : Optimum exact calculable directement (pas besoin d'itérations)
  • Baseline parfaite : Excellent point de départ pour tout projet ML

❌ Inconvénients & Limites

  • Relations linéaires uniquement : Ne capture pas les relations complexes/non-linéaires
  • Sensible aux outliers : MSE pénalise fortement les valeurs aberrantes (au carré)
  • Hypothèses strictes : Assume indépendance des features, homoscédasticité, normalité des erreurs
  • Multicolinéarité : Problèmes si features corrélées entre elles
  • Extrapolation dangereuse : Prédictions hors domaine d'entraînement peu fiables

💡 Cas d'usage recommandés

  • Prédiction de prix : Immobilier (surface → prix), ventes (budget pub → revenus)
  • Prévisions simples : Tendances temporelles linéaires, croissance
  • Modèle baseline : Toujours commencer par régression linéaire avant modèles complexes
  • Données tabulaires : Features numériques continues avec relation approximativement linéaire
  • Interprétabilité critique : Secteur médical, finance (besoin d'expliquer les décisions)
  • Peu de données : Fonctionne bien même avec datasets réduits

⚠️ Pièges à éviter

  • Outliers non traités : Toujours visualiser et gérer les valeurs aberrantes (MAE ou robustesse)
  • Multicolinéarité ignorée : Vérifier VIF (Variance Inflation Factor) ou utiliser régularisation (Ridge/Lasso)
  • Extrapolation aveugle : Ne jamais prédire loin des données d'entraînement
  • Relations non-linéaires : Transformer features (log, polynomial) ou passer à modèles non-linéaires
  • Features non normalisées : Standardiser si échelles très différentes (régularisation)
  • Overfitting avec trop de features : Utiliser régularisation (Ridge, Lasso, ElasticNet)

🎯 En production : Checklist décisionnelle

Utilisez la régression linéaire si :

  • ✓ Relation approximativement linéaire entre X et y
  • ✓ Besoin d'interprétabilité claire des résultats
  • ✓ Budget computationnel limité (rapidité critère)
  • ✓ Première itération / baseline du projet

Passez à autre chose si :

  • ✗ Relation clairement non-linéaire (courbes, interactions complexes)
  • ✗ Besoin de performance maximale (privilégier Random Forest, Gradient Boosting)
  • ✗ Beaucoup d'outliers non gérables (essayer MAE ou modèles robustes)
