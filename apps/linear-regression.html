Régression Linéaire

Convergence de l'erreur

🎓 Comment ça marche ?

La régression linéaire utilise la descente de gradient pour optimiser les paramètres m (pente) et b (ordonnée). Vous pouvez choisir différentes fonctions de perte:

MSE (Mean Squared Error)

MSE = (1/n) Σ (yᵢ - ŷᵢ)²

Sensible aux outliers, pénalise fortement les grandes erreurs (au carré)

MAE (Mean Absolute Error)

MAE = (1/n) Σ |yᵢ - ŷᵢ|

Robuste aux outliers, traite toutes les erreurs de manière égale (valeur absolue)

RMSE (Root Mean Squared Error)

RMSE = √[(1/n) Σ (yᵢ - ŷᵢ)²]

Sensible aux outliers comme MSE, mais dans la même unité que les données

Le graphique de convergence affiche simultanément les 3 métriques pour comparer leur évolution pendant l'optimisation. La fonction de perte sélectionnée détermine les gradients utilisés pour la descente de gradient.

Expérience: Ajoutez des points avec outliers et observez comment les 3 courbes évoluent différemment!
