📚 Définitions Clés - CNN

Convolution
Opération qui applique un filtre (matrice de poids) sur l'image en le faisant glisser. Chaque filtre détecte une caractéristique spécifique (bord, coin, texture).
Kernel / Filtre
Petite matrice (ex: 3x3) de poids qui parcourt l'image. Les valeurs du filtre déterminent quelle caractéristique il détecte (horizontal, vertical, diagonal).
Feature Map (Carte de Caractéristiques)
Résultat de l'application d'un filtre sur l'image. Montre où dans l'image la caractéristique est présente (zones colorées = forte activation).
Pooling
Opération qui réduit la taille de la feature map en prenant une valeur représentative (max ou moyenne) dans chaque région. Rend le réseau plus robuste et réduit le calcul.
Stride (Pas)
Nombre de pixels dont le filtre se déplace à chaque étape. Stride = 1 signifie déplacement pixel par pixel, stride = 2 saute un pixel à chaque fois.
Padding (Remplissage)
Ajout de pixels (souvent des 0) autour de l'image pour contrôler la taille de sortie et préserver les informations des bords.

🎓 Réseaux de Neurones Convolutifs (CNN)

Les CNN ont révolutionné la vision par ordinateur. Inventés par Yann LeCun en 1989 (LeNet), ils sont devenus essentiels avec AlexNet (2012) qui a remporté ImageNet.

Couche Convolutive: Y = f(W ★ X + b)

Pourquoi les CNN sont spéciaux:

• Filtres de convolution: Au lieu de connecter tous les pixels à tous les neurones, on applique de petits filtres (3x3, 5x5) qui glissent sur l'image. Chaque filtre détecte une caractéristique spécifique (bords, coins, textures).

• Partage de poids: Le même filtre est appliqué partout dans l'image, réduisant drastiquement le nombre de paramètres à apprendre.

• Hiérarchie de caractéristiques: Les premières couches détectent des caractéristiques simples (bords), les couches suivantes combinent ces caractéristiques pour détecter des formes plus complexes (yeux, nez), puis des objets entiers (visages, voitures).

Max Pooling: Y[i,j] = max(X[2i:2i+2, 2j:2j+2])

Max Pooling: Réduit la taille des feature maps en prenant la valeur maximale dans chaque région 2x2. Cela rend le réseau plus robuste aux petites translations et réduit le calcul.

Architecture typique d'un CNN:
Input → [Conv → ReLU → Pool] × N → Flatten → Dense → Softmax → Output

Applications: Reconnaissance d'images, détection d'objets, segmentation sémantique, reconnaissance faciale, voitures autonomes, diagnostic médical, et bien plus!

📊 Analyse : Quand utiliser les CNN ?

✅ Avantages

  • Invariance spatiale : Détecte features indépendamment de leur position (translation invariance)
  • Partage de poids : Même filtre réutilisé partout → beaucoup moins de paramètres que Dense layers
  • Hiérarchie de features : Couches basses = bords, couches hautes = concepts complexes
  • SOTA en vision : Meilleure architecture pour images (ResNet, EfficientNet, Vision Transformers)
  • Transfer learning facile : Modèles pré-entraînés (ImageNet) réutilisables
  • Robustesse : Pooling rend résistant aux petites déformations/translations

❌ Inconvénients & Limites

  • Beaucoup de données nécessaires : Millions d'images pour entraînement from scratch
  • Calculs intensifs : Entraînement lent, nécessite GPU/TPU
  • Boîte noire : Difficile d'interpréter pourquoi une décision est prise
  • Sensible aux adversarial attacks : Modifications pixel imperceptibles trompent le modèle
  • Overfitting facile : Sans augmentation de données et régularisation
  • Taille d'image fixe : Nécessite redimensionnement des inputs (sauf architectures spéciales)

💡 Cas d'usage recommandés

  • Classification d'images : Animaux, objets, scènes (ImageNet, CIFAR)
  • Détection d'objets : YOLO, Faster R-CNN (voitures autonomes, vidéosurveillance)
  • Segmentation sémantique : U-Net (imagerie médicale, segmentation de tumeurs)
  • Reconnaissance faciale : FaceNet, ArcFace (authentification, sécurité)
  • Génération d'images : StyleGAN, DALL-E (art génératif, design)
  • Vision par ordinateur : OCR, analyse de documents, réalité augmentée

⚠️ Pièges à éviter

  • Pas d'augmentation de données : Toujours utiliser rotation, flip, crop, color jitter
  • Entraînement from scratch : Préférer transfer learning (ResNet50, EfficientNet pré-entraînés)
  • Batch size trop petit : BatchNorm nécessite batch size ≥ 16, idéalement 32-128
  • Learning rate mal réglé : Utiliser warm-up + cosine decay, tester plusieurs valeurs
  • Ignorer le déséquilibre de classes : Utiliser weighted loss ou oversampling
  • Pas de validation : Toujours garder 10-20% des données pour validation

🎯 En production : Checklist décisionnelle

Utilisez les CNN si :

  • ✓ Données = images (2D) ou séries temporelles (1D CNN)
  • ✓ Besoin d'invariance spatiale (détection de patterns partout)
  • ✓ Dataset conséquent (ou transfer learning possible)
  • ✓ GPU disponible pour entraînement

Alternatives si :

  • Peu de données : Transfer learning OBLIGATOIRE (ou datasets synthétiques)
  • Données non-images : MLP, RNN, Transformers selon le type
  • Relations globales importantes : Vision Transformers (ViT) > CNN
  • Interprétabilité critique : Attention maps, GradCAM pour explications

⚡ Best Practice 2025 : Pour prototypage rapide, utilisez PyTorch/TensorFlow avec modèles pré-entraînés (timm, torchvision). Fine-tuning sur votre dataset custom = 10x plus rapide que from scratch.
