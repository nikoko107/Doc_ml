📖 Comprendre les Graph Neural Networks

🎯 Innovation

Étendre les réseaux de neurones aux données non-euclidiennes (graphes). Capture la structure relationnelle entre entités.

⚡ Applications

Réseaux sociaux, molécules, knowledge graphs, systèmes de recommandation, code source, circuits électroniques

🔬 Message Passing Framework

1️⃣ Message Génération

mu→v(k) = MSG(k)(hu(k), hv(k), euv)

Chaque noeud u génère un message pour ses voisins v. Peut inclure les features de l'arête euv.

2️⃣ Message Agrégation

mv(k) = AGG(k)({mu→v(k), ∀u ∈ N(v)})

AGG peut être: SUM, MEAN, MAX, LSTM, Attention
Fonction permutation-invariante (ordre des voisins n'importe pas)

3️⃣ Node Update

hv(k+1) = UPDATE(k)(hv(k), mv(k))

Combiner l'ancien état hv(k) avec messages agrégés.
Souvent: hv(k+1) = σ(W · [hv(k) || mv(k)])

🏗️ Architectures Populaires

GCN (Graph Convolutional Network)

hv(k+1) = σ(W(k) · Σu∈N(v)∪{v} hu(k) / √(du·dv))

AGG = normalized sum. dv = degré du noeud. Simple et efficace.

GraphSAGE

hv(k+1) = σ(W(k) · [hv(k) || AGG({hu(k), u∈N(v)})])

AGG = MEAN, LSTM, or MAX pooling. Scalable à grands graphes via sampling.

GAT (Graph Attention Networks)

αuv = softmax(LeakyReLU(aT[Whu||Whv]))
hv(k+1) = σ(Σu∈N(v) αuv W hu(k))

Attention pondérée sur voisins. Multi-head comme Transformers.

📊 Tâches et Applications

Node Classification

Prédire catégorie/propriété d'un noeud.
Ex: Détection de fraude, catégorisation utilisateurs, prédiction de protéines

Link Prediction

Prédire arêtes manquantes/futures.
Ex: Recommandation d'amis, drug-target interaction, knowledge graph completion

Graph Classification

Classifier graphes entiers.
Ex: Propriétés moléculaires, classification de code source, analyse de réseaux

🚀 Cas d'Usage Réels

  • Pinterest: PinSage (GraphSAGE) pour recommandation de pins, 3B noeuds
  • Google Maps: ETA prediction avec GNN sur road network
  • DeepMind: AlphaFold 2 utilise GNN pour prédire structures protéines
  • Drug Discovery: Prédiction propriétés moléculaires (Chemprop, GNN)
  • Facebook: Detection de fake news via propagation dans graphe social
  • Alibaba: Fraud detection dans réseau de transactions

⚙️ Défis & Solutions

  • Over-smoothing: Après k couches, tous les noeuds convergent. Solution: skip connections, attention
  • Scalabilité: Graphes géants (millions noeuds). Solution: mini-batch, sampling (GraphSAGE)
  • Hétérogénéité: Types de noeuds/arêtes différents. Solution: Heterogeneous GNN (HAN, HGT)
  • Dynamic graphs: Structure évolue. Solution: Temporal GNN (TGAT, EvolveGCN)
