🎓 La Descente de Gradient

La descente de gradient est l'algorithme d'optimisation fondamental utilisé pour entraîner les réseaux de neurones et la plupart des modèles de machine learning.

θ = θ - α ∇f(θ)

Où θ sont les paramètres, α est le taux d'apprentissage (learning rate), et ∇f(θ) est le gradient (dérivée) de la fonction de coût.

Comment ça marche: Imaginez que vous êtes dans le brouillard au sommet d'une montagne et vous voulez descendre. À chaque pas, vous regardez la pente autour de vous et vous faites un pas dans la direction la plus descendante. C'est exactement ce que fait la descente de gradient!

Le taux d'apprentissage détermine la taille de chaque pas:

• Trop petit: convergence très lente
• Trop grand: risque de diverger ou d'osciller
• Optimal: convergence rapide et stable

Variantes modernes: SGD (Stochastic), Adam, RMSprop, AdaGrad - qui adaptent le taux d'apprentissage automatiquement pour une meilleure performance.

📚 Définitions

Gradient ?
Vecteur des dérivées partielles qui indique la direction et l'intensité de la plus forte augmentation de la fonction
Minimum Local ?
Point où la fonction atteint son minimum dans une région locale, mais qui peut ne pas être le minimum global
Fonction de Coût ?
Fonction mathématique qui quantifie l'erreur du modèle. L'objectif est de la minimiser
Convergence ?
État où l'algorithme a atteint un minimum et les changements deviennent négligeables

⚙️ Comment ça marche ?

  1. Initialisation : Commencer avec des paramètres aléatoires θ₀ (position de départ)
  2. Calcul de la fonction de coût : Évaluer J(θ) - mesure de l'erreur actuelle
  3. Calcul du gradient : Calculer ∇J(θ) - direction de la plus forte montée
  4. Mise à jour des paramètres : θ = θ - α·∇J(θ) - faire un pas dans la direction opposée au gradient
  5. Itération : Répéter les étapes 2-4 jusqu'à convergence (gradient ≈ 0 ou nombre max d'itérations)

💡 Le signe négatif est crucial : on descend dans la direction OPPOSÉE au gradient (qui pointe vers la montée)

📊 Analyse : Quand utiliser la descente de gradient ?

✅ Avantages

  • Universel : Fonctionne pour toute fonction différentiable
  • Scalable : S'adapte à des millions/milliards de paramètres
  • Base du deep learning : Utilisé pour entraîner tous les réseaux de neurones
  • Variantes puissantes : SGD, Adam, RMSprop adaptent automatiquement le learning rate
  • Garanties théoriques : Converge vers minimum global pour fonctions convexes
  • Simple à implémenter : Quelques lignes de code suffisent

❌ Inconvénients & Limites

  • Choix du learning rate critique : Trop grand → divergence, trop petit → lenteur extrême
  • Minima locaux : Peut rester bloqué dans un minimum local (non-global)
  • Plateaux : Ralentissement extrême dans les zones plates (gradient ≈ 0)
  • Vanishing gradient : Gradients trop petits dans les réseaux profonds
  • Sensibilité à l'initialisation : Point de départ impacte fortement le résultat
  • Coût computationnel : Calcul du gradient sur tout le dataset (batch GD)

💡 Cas d'usage recommandés

  • Réseaux de neurones : Entraînement de tous types (CNN, RNN, Transformers, etc.)
  • Régression linéaire/logistique : Alternative à la solution analytique pour gros datasets
  • Optimisation générale : Minimiser toute fonction de coût différentiable
  • Transfer learning : Fine-tuning de modèles pré-entraînés
  • Apprentissage en ligne : Mise à jour continue avec nouvelles données (SGD)
  • Systèmes à grande échelle : Millions de paramètres (GPU/TPU)

⚠️ Pièges à éviter

  • Learning rate fixe : Utiliser des schedulers (decay, warm-up) ou optimiseurs adaptatifs (Adam)
  • Batch GD sur gros datasets : Préférer mini-batch SGD ou SGD stochastique
  • Pas de normalisation : Toujours standardiser les features (mean=0, std=1)
  • Ignorer l'initialisation : Utiliser Xavier/He initialization pour réseaux profonds
  • Convergence prématurée : Vérifier plusieurs runs avec initialisations différentes
  • Gradient explosion : Clipper les gradients (gradient clipping) pour réseaux récurrents

🎯 En production : Choix de l'optimiseur

Recommandations par cas d'usage :

  • Vision (CNN) : SGD avec momentum (0.9) + weight decay
  • NLP (Transformers) : Adam ou AdamW avec warm-up
  • Prototypage rapide : Adam (learning rate adaptatif, converge vite)
  • Production critique : SGD avec tuning manuel (meilleure généralisation)

⚡ Astuce : Toujours commencer avec Adam (lr=1e-3 ou 3e-4) pour valider rapidement, puis passer à SGD si besoin de squeeze les derniers % de performance.
