📚 Guide de Formation Machine Learning

Programme structuré pour une journée complète de formation
Des fondamentaux historiques aux architectures modernes d'IA

🎯 Objectifs pédagogiques

À la fin de cette journée de formation, les participants seront capables de :

  • Comprendre l'évolution du Machine Learning depuis les années 1800 jusqu'aux LLMs modernes
  • Maîtriser les concepts fondamentaux : régression, classification, clustering, réseaux de neurones
  • Visualiser concrètement comment fonctionnent les algorithmes grâce aux applications interactives
  • Évaluer correctement les performances d'un modèle en production
  • Comprendre les architectures modernes : Transformers, RAG, LoRA, Diffusion Models

💾 Préparation de la formation

Aucune installation requise ! Toutes les applications fonctionnent directement dans le navigateur.

Prérequis :

  • Navigateur web moderne (Chrome, Firefox, Edge, Safari)
  • Connaissances de base en mathématiques (algèbre, fonctions)
  • Curiosité et envie d'apprendre ! 🚀

Conseil : Ouvrez chaque application dans un nouvel onglet pour pouvoir revenir facilement au guide. Utilisez Ctrl+Clic (ou Cmd+Clic sur Mac) sur les liens.

Session 1 : Les Fondations du Machine Learning

Commencez par les bases historiques. Comprenez comment tout a débuté avec la régression linéaire et évoluez vers les premiers réseaux de neurones.

Concepts clés : Prédiction, classification, descente de gradient, fonction de coût

  • Régression Linéaire 25 min
  • Descente de Gradient 20 min
  • Perceptron (1958) 20 min
  • K-Means Clustering 15 min

💡 Point pédagogique : Insistez sur le fait que la descente de gradient est au cœur de TOUT l'apprentissage moderne. Tous les algorithmes suivants l'utilisent.

Session 2 : Réseaux de Neurones & Deep Learning

Passez aux réseaux de neurones multicouches et au Deep Learning. Visualisez comment la backpropagation permet d'entraîner des réseaux profonds, et découvrez les CNNs.

Concepts clés : Couches cachées, activations, backpropagation, convolution, pooling

  • Réseau de Neurones Multicouche 25 min
  • Backpropagation 20 min
  • Cycle d'Entraînement Complet 20 min
  • CNN - Réseaux Convolutifs 25 min
  • Bonus : SVM (si temps) 15 min

💡 Point pédagogique : Les CNNs ont révolutionné la vision par ordinateur en 2012 (AlexNet). Montrez comment les filtres de convolution extraient automatiquement les caractéristiques.

Session 3 : NLP & Traitement du Langage

Découvrez comment les ordinateurs comprennent le langage humain. De l'encodage simple aux embeddings vectoriels qui capturent le sens des mots.

Concepts clés : Encodage, fréquences, TF-IDF, embeddings, espace sémantique

  • One-Hot Encoding 12 min
  • Bag of Words 12 min
  • TF-IDF 15 min
  • Word Embeddings 20 min

⚡ Moment "Wow" : L'animation Roi - Homme + Femme = Reine est toujours impressionnante ! C'est le pont vers les Transformers de la session suivante.

Session 4 : Évaluation & Algorithmes Avancés

Apprenez à évaluer correctement vos modèles ! Découvrez aussi des algorithmes plus avancés : ensemble learning, algorithmes génétiques, reinforcement learning.

Concepts clés : Métriques, ROC/AUC, ensemble learning, évolution, Q-learning

  • Métriques & Évaluation 15 min
  • Prétraitement de Données 12 min
  • Random Forest 10 min
  • Choisir : Algo Génétique OU Q-Learning 8 min

💡 Point important : L'évaluation est CRITIQUE en production. Un modèle avec 95% d'accuracy peut être inutile si vous avez des classes déséquilibrées !

Session 5 : IA Moderne - Transformers & LLMs

Le grand final ! Explorez les architectures qui ont révolutionné l'IA depuis 2017 : Transformers, GPT, RAG, LoRA, et les modèles de diffusion.

Concepts clés : Attention, Q·K·V, génération de texte, RAG, fine-tuning, diffusion

  • Transformers & Attention 25 min
  • Beam Search & Température 15 min
  • RAG - Retrieval Augmented Generation 12 min
  • Prompts & Mémoire 10 min
  • LoRA - Fine-tuning Efficace 12 min
  • Modèles de Diffusion 10 min
  • Bonus : MCP et GNN 6 min

🎆 Grand finale : Cette session montre l'état de l'art actuel. Les Transformers (2017) ont permis GPT, BERT, Claude, ChatGPT. Les modèles de diffusion ont créé Stable Diffusion et DALL-E !

💡 Conseils pour animer la formation

  • Soyez interactif : Laissez les participants manipuler les applications eux-mêmes
  • Posez des questions : "Que se passe-t-il si on augmente le learning rate ?" "Pourquoi MSE est sensible aux outliers ?"
  • Faites des analogies : La descente de gradient = descendre une montagne dans le brouillard
  • Montrez les maths ET l'intuition : Les formules sont importantes, mais l'intuition l'est encore plus
  • Adaptez le rythme : Certains concepts peuvent nécessiter plus de temps selon le public
  • Utilisez les exemples concrets : "Netflix utilise ça pour...", "Spotify fait comme ça..."
  • Prenez des pauses : Le Machine Learning est dense, les cerveaux ont besoin de repos !

🎓 Variantes selon le niveau

Public débutant :

  • Insistez sur Sessions 1, 2 et 3 (fondamentaux + deep learning + NLP)
  • Allez moins vite sur la descente de gradient et backpropagation
  • Simplifiez la Session 5, montrez surtout l'attention des Transformers

Public avancé :

  • Accélérez les Sessions 1-2 (fondamentaux connus)
  • Approfondissez Session 5 (RAG, LoRA, MCP, GNN)
  • Ajoutez des discussions sur l'implémentation pratique en production
  • Explorez tous les bonus (SVM, Algo Génétique, Q-Learning, GNN)
